# 漫游地球 · 全球旅行地图

在线访问：<https://aofeng188.github.io/>

这个仓库是网站的静态发布产物（构建后的页面、脚本、数据与图片），由源码项目里的 `scripts/deploy-pages.sh` 生成，请勿直接修改。

## 数据与图片许可

- 合并后的地点数据库按 ODbL 1.0 提供；各独立来源（Wikidata、Overture Maps、OpenStreetMap、文旅部公开名录、中国旅游地点研究资料等）的 CC0、CDLA、Apache、CC BY、CC BY-SA 许可继续保留，每条记录的来源可在站内「资料来源」查看。
- 每张照片适用各自的许可，作者与许可见站内「图片署名」。
- 地图影像来自 NASA／GEBCO，底图来自 OpenFreeMap／OpenStreetMap，署名显示在地图左下角。
