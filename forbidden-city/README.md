# 紫禁城漫游

在浏览器里三维漫游北京故宫。所有建筑都由代码按真实格局和比例生成（Three.js），不依赖任何模型或图片文件。

在线访问（合并到 `main` 后由 GitHub Pages 提供）：<https://aofeng188.github.io/forbidden-city/>

## 功能

- **鸟瞰**：拖动旋转、缩放、平移；点击建筑查看介绍，镜头会飞到建筑前。
- **漫步**：第一人称行走，有碰撞（台阶、台基、门洞、拱桥都能走），按 `F` 切换飞行。手机上用左下摇杆移动、滑动屏幕转向。
- **导览**：沿中轴线自动游览 16 站（天安门 → 景山），配中文语音解说，并进入太和殿、乾清宫室内。
- **室内**：太和殿（宝座、蟠龙金柱、藻井与轩辕镜、"建极绥猷"匾）、乾清宫（"正大光明"匾）、养心殿（"中正仁和"匾）。
- **信息**：60 多座建筑的介绍卡片、建筑索引与搜索、小地图和全图、30 多个古建知识标注（屋顶形制、脊兽、斗拱、彩画、螭首、日晷嘉量等）。
- **环境**：时辰（太阳按北京纬度和季节计算）、四季（树木颜色、花期、落叶）、落雪（屋顶与地面积雪、护城河结冰）、夜景灯光、护城河与金水河倒影。
- **声音**：Web Audio 实时合成的风声、鸟鸣、黄昏乌鸦、虫鸣、游客低语、脚步声，以及 D 宫五声音阶的古筝与箫配乐。

## 范围

南起长安街与天安门，经端门、午门，覆盖紫禁城全部区域（中轴线、外朝东西路、东西六宫、养心殿、慈宁宫、宁寿宫区等），北至景山。天安门东西两侧的太庙与社稷坛、宫城外的胡同以简化形式表现。

建筑的位置、尺度和形制参考公开资料近似复原，次要院落的位置做了简化，不是测绘级的精确模型。

## 结构

```
index.html            页面、样式与界面
js/main.js            主程序：模式切换、导览、卡片、设置、主循环
js/core/              几何缓冲、程序化纹理、材质（积雪/夜景注入）、天空环境、相机控制、声音、场景生成
js/build/             屋顶、殿堂、城门、城墙、角楼、陈设、室内、文字图集
js/world/             总体布局、地面水系、碰撞网格、树木、游客、水面
js/data/              建筑介绍、古建知识、导览解说
```

没有构建步骤：浏览器直接加载 ES 模块，Three.js（0.180.0）通过 import map 从 jsDelivr 加载。本地预览：

```
npx http-server forbidden-city -p 8080
```
